# 🖥️ 4-Bit Computer Architecture using CPU Sim 4

A **4-bit computer architecture** designed and simulated using **CPU Sim 4** to explore the fundamental concepts of computer organization, instruction execution, arithmetic operations, and memory management.

## 📌 Project Overview

This project involves designing a custom 4-bit CPU using CPU Sim 4. It demonstrates how a processor performs arithmetic and logical operations, manages registers, accesses memory, and executes instructions. The project also includes a program to calculate the sum of integers, providing practical experience with basic CPU operations.

## ⚙️ Features

* **Arithmetic Operations:** Implementation of addition and subtraction to perform basic mathematical calculations.
* **Logical Operations:** Execution of logical instructions to understand Boolean operations and data processing.
* **Memory Reference Instructions:** Instructions for accessing memory, transferring data, and performing operations using memory locations.
* **Register Reference Instructions:** Operations performed directly on CPU registers for efficient data manipulation and control.
* **Sum of Integers:** A program that calculates the sum of integers using the implemented instruction set.
* **4-Bit Architecture:** A custom-designed CPU with 4-bit data handling and configurable registers.
* **Instruction Execution:** Demonstration of the fetch, decode, and execute cycle.

## 🧩 Main Components

* **Registers:** Temporarily store data and intermediate results during instruction execution.
* **ALU:** Performs arithmetic and logical operations.
* **Memory:** Stores instructions and data required by the CPU.
* **Control Unit:** Coordinates instruction execution and manages CPU operations.
* **Instruction Set:** Defines the arithmetic, logical, memory-reference, and register-reference operations supported by the machine.

## 🔄 Instruction Categories

| Category           | Description                               |
| ------------------ | ----------------------------------------- |
| Addition           | Adds two values                           |
| Subtraction        | Subtracts one value from another          |
| Logical Operations | Performs logical calculations             |
| Memory Reference   | Accesses and manipulates memory data      |
| Register Reference | Performs operations directly on registers |
| Sum of Integers    | Calculates the sum of multiple integers   |

## 🚀 How to Run

1. Install and open CPU Sim 4.
2. Load the custom 4-bit machine configuration.
3. Configure the registers, memory, and instruction set.
4. Load or write a program using the supported instructions.
5. Execute the program using the simulator.
6. Observe the changes in registers, memory, and output.
