# 🖥️ 4-Bit Computer using CPU Sim 4

A 4-bit computer architecture designed and simulated using **CPU Sim 4** to understand the fundamentals of computer organization and processor design.

## ⚙️ Features

* 4-bit CPU architecture
* Custom-configured registers
* Memory organization
* Instruction set design
* Instruction fetch, decode and execute cycle
* Basic data transfer and processing

## 🛠️ Tools Used

* CPU Sim 4
* Computer Architecture

## 🚀 How to Run

1. Open CPU Sim 4.
2. Load the machine configuration.
3. Load or enter a program.
4. Execute instructions and observe register and memory changes.

## 🎯 Objective

To understand CPU architecture, register operations, memory, and instruction execution through simulation.
